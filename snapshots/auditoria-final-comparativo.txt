AUDITORIA FINAL COMPARATIVA - CENARIO A x CENARIO B

=== OWASP ZAP ===
Cenario A (baseline, antes das defesas):
  High: 0 | Medium+Low (WARN): 22 | PASS: 45

Cenario B (apos hardening de cabecalhos):
  High: 0 | Medium: 4 | Low: 7 | Informational: 10
  Total Medium+Low: 11

TAXA DE MITIGACAO (ZAP): de 22 para 11 avisos = reducao de 50%

Avisos eliminados, atribuiveis diretamente ao hardening desenvolvido:
  - Missing Anti-clickjacking Header (X-Frame-Options aplicado)
  - X-Content-Type-Options Header Missing (nosniff aplicado)
  - CSP Header Not Set (Content-Security-Policy aplicada)
  - Permissions Policy Header Not Set (Permissions-Policy aplicada)
  - Server Leaks Version via Server header (ServerTokens Prod aplicado)
  - Cookie without SameSite Attribute (regra de cookie aplicada)

Avisos remanescentes no Cenario B (fora do escopo do hardening aplicado):
  - Cookie No HttpOnly Flag (pendente - regra nao cobriu todos os cookies)
  - Information Disclosure - Sensitive Information in URL
  - Information Disclosure - Suspicious Comments
  - Cookie Poisoning
  - User Controllable HTML Element Attribute (XSS potencial)
  - Server Leaks via X-Powered-By (pendente - requer expose_php=Off)
  - Non-Storable Content

=== SQLMap ===

Cenario B: "all tested parameters do not appear to be injectable" apos
  desenvolvimento de consulta parametrizada + validacao de tipo.
TAXA DE MITIGACAO (SQLi): de vulneravel (3 tecnicas, extracao completa de
  dados) para nao explorável = mitigacao de 100% no ponto testado.
